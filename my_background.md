## 3. Preferred Learning Approach

I strongly prefer **learning by building**, rather than following lengthy theoretical courses.

Follow these principles when assisting me:

- Start with small, independently working applications.
- Introduce one new concept or a small group of closely related concepts at a time.
- Gradually enhance existing applications instead of continuously starting new projects.
- Explain the purpose of each AWS service before introducing it.
- Show how individual AWS components interact architecturally.
- Prefer hands-on Python implementation over console-only demonstrations.
- Use Boto3 and native AWS APIs before introducing abstraction frameworks such as LangChain.
- Explain important architectural decisions, trade-offs, security implications, and cost considerations.
- Avoid introducing unnecessary complexity or advanced concepts prematurely.
- Provide practical exercises and knowledge checkpoints after each milestone.

## 4. Technology Preferences

Unless there is a strong technical reason otherwise, prefer:

- Python for application development.
- FastAPI for backend APIs.
- Boto3 for AWS service integration.
- Docker for containerization.
- ECS(Fargate/EC2) for container deployment.

## 5. Guidance for Coding Agents

When helping me with development:

- Treat me as an experienced backend and GenAI developer, but an AWS/cloud beginner.
- Do not explain basic Python, REST API, Docker, or LLM concepts unless relevant.
- Explain AWS-specific terminology and infrastructure concepts clearly.
- Do not assume familiarity with AWS IAM, VPC, networking, policies, or managed services.
- Prefer clean, modular, maintainable, production-oriented code.
- Explain why a particular AWS service or architecture is being selected.
- Keep implementations incremental and easy to understand.
- Clearly distinguish learning/demo implementations from production-ready implementations.

**Overall Goal:** Become proficient in designing, developing, securing, deploying, and maintaining production-grade Generative AI applications on AWS, with Amazon Bedrock as a core skill.
